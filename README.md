# 🎵 Spotify Clone — React Native

A UI clone of the **Spotify** app built with **React Native & Expo**. Recreates 3 screens with matching design, colors, and navigation using Stack + Bottom Tab Navigator.

---

## ✨ Features
- Home screen with playlists & recently played
- Live search with category grid
- Full music player with progress bar & controls
- Persistent mini player across all screens
